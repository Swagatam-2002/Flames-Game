# 🔥 FLAMES Web App

A simple and fun **FLAMES Relationship Calculator** built with **Python and Flask**.

## ✨ Features

* Enter two names and calculate FLAMES
* Attractive responsive UI
* 🔄 Play Again option
* 🔗 Copy game link
* 📤 Share with friends
* Mobile-friendly design

## 🛠️ Technologies

* Python
* Flask
* HTML
* CSS
* JavaScript

## 📁 Project Structure

```text
FLAMES_Web_App/
├── app.py
├── flames.py
├── requirements.txt
├── .gitignore
├── templates/
│   └── index.html
└── static/
    └── style.css
```

## ▶️ Run Locally

```bash
pip install -r requirements.txt
python app.py
```

Then open:

```text
http://127.0.0.1:5000
```
